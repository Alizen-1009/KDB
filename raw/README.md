# Raw 数据区

这里存放未经整理的原始资料，是整个知识库的事实来源。

## 子目录说明

- `articles/`：博客、公众号文章、技术评论、设计说明
- `papers/`：论文、技术报告、白皮书
- `repos/`：源码、README、设计文档、issue 摘要
- `datasets/`：benchmark、评测集、实验结果说明
- `images/`：架构图、性能图、截图、表格图片
- `code/`：配置片段、脚本、kernel 示例、最小复现代码

建议命名方式：

`年份-来源或作者-主题关键词.ext`

例如：

- `2025-tri-dao-flashattention-3.pdf`
- `2026-vllm-v1-architecture.md`
- `2025-sglang-scheduling-design.md`
- `2026-mlperf-inference-v5-results.csv`
