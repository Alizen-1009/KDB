# 单核上两个线程何时可能比一个线程更快？

## 原题与条件

单核什么情况下会出现两个线程比一个线程的耗时更短？

## 30 秒回答

先区分一个逻辑 CPU 和一颗支持 SMT 的物理核。单逻辑 CPU 上，一个线程阻塞等待 I/O 时，另一个线程可利用 CPU；SMT 还可能利用停顿期间空闲的执行资源。纯计算已占满资源时，两线程通常只增加切换和竞争，不能把线程数当成算力翻倍。

## 深入解释

- 一个逻辑 CPU：线程 A 等待外部 I/O、睡眠或其他阻塞事件时，线程 B 可以运行，使两个独立任务的总墙钟时间缩短。前提是工作能重叠，而非强依赖串行。
- 一颗物理核、多个 SMT 硬件线程：若一个线程因 cache miss 或依赖链停顿，另一个可能使用空闲执行资源；也可能争用缓存、带宽或执行端口而变慢。
- 纯计算且已充分利用同一逻辑 CPU：并发软件线程一般不能同时执行更多指令，反而有切换开销。

用户态线程、OS 线程、硬件线程不是同一层；语言运行时也会影响执行，例如不能把 Python 线程结论不加条件地推广到 C++。
