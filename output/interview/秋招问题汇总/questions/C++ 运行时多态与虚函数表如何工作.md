# C++ 运行时多态与虚函数表如何工作？

- 整理状态：已整理
- 题目出处：用户提供的 SDE / 强化学习岗位面试回忆

## 30 秒回答

通过基类指针或引用调用 virtual 函数，通常按对象动态类型分派到最终 override。常见 ABI 用对象中的 vptr 定位共享 vtable，再按槽位调用。

## 深入解释

用 override 让编译器检查签名。通过基类指针销毁派生对象时，普通 delete 场景应给基类虚析构。按值传基类可能发生切片；构造和析构期间的虚调用按当前构造/析构层分派；默认参数由静态类型决定。编译器能证明目标时可去虚化。虚表布局是 ABI 细节，多重继承可能需要多个 vptr 及调整 this 的 thunk。

静态多态包括模板与重载，编译期确定；动态多态依赖虚函数分派。C++ 标准不规定虚表及其槽位顺序，具体取决于 ABI；常见单继承布局中基类虚函数按 ABI 分配槽位，重写覆盖对应槽位，派生类新增虚函数通常获得新槽位。析构函数、多重继承和虚继承可能带来额外入口或调整，不能一概断言严格按声明顺序。
