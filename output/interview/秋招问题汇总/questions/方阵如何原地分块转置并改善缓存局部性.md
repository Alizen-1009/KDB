# 方阵如何原地分块转置并改善缓存局部性？

- 整理状态：已整理
- 题目出处：[小红书分享图转录](https://chatgpt.com/library?file_id=libfile_08e498b5bde48191b68600b6e5b9507d&account_id=personal)，第 26 题

## 原题与条件

26. 给定一个 N×N 矩阵，设计算法原地转置，要求仅使用 O(1) 额外空间，并讨论缓存友好性。

## 30 秒回答

只交换上三角 A[i,j] 和 A[j,i]，O(N²) 时间与 O(1) 额外空间。按块配对改善缓存局部性。

## 深入解释

行主序直接交换时一侧连续、一侧跨行。固定块长把访问局部化，边缘块用 min 裁切。对角块只扫块内上三角，非对角块只处理一侧。

```cpp
void transpose(float* a, std::size_t n) {
    constexpr std::size_t B = 32;
    for (std::size_t bi = 0; bi < n; bi += B) {
        const auto i_end = bi + std::min(B, n - bi);
        for (std::size_t bj = bi; bj < n; bj += B) {
            const auto j_end = bj + std::min(B, n - bj);
            for (std::size_t i = bi; i < i_end; ++i) {
                const auto first_j = bi == bj ? i + 1 : bj;
                for (std::size_t j = first_j; j < j_end; ++j)
                    std::swap(a[i * n + j], a[j * n + i]);
            }
        }
    }
}
```

B 是示例值，按元素大小、cache 和实测调整。
