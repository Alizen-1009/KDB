# 两个指针指向常量时如何交换它们的指向？

- 整理状态：已整理
- 题目出处：用户提供的《英伟达 AI Infra 五面面经》截图，C++第 2 题；2026-11-05 收录，实际面试日期与具体轮次未提供。

## 原题与条件

A 指向 1，B 指向 2，交换 A 和 B，1 和 2 是常量。

## 30 秒回答

常量值不可改，不妨碍交换可修改的指针变量。把 A 和 B 的指针值交换即可，常量对象仍是原来的 1 和 2。如果 A、B 自身也声明为 const 指针，则不能直接修改指向。

## 深入解释

```cpp
#include <utility>

const int one = 1;
const int two = 2;
const int* A = &one;
const int* B = &two;
std::swap(A, B);
// A 指向 two，B 指向 one；常量对象未改变。
```

`const int*` 限制通过指针修改目标；`const int* const` 还限制指针本身。不能把“交换 A/B”偷偷改成写入 *A/*B，也不能用 const_cast 修改真正的 const 对象。

相关：[[const int 指针的两种写法与常量指针有什么区别|指针的 const 位置]]。
