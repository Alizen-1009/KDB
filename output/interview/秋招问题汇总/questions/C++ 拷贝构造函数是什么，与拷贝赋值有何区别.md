## 原题与条件

C++ 拷贝构造函数是什么？

## 30 秒回答

拷贝构造用已有对象初始化同类型新对象，常见签名为 T(const T&)。T b=a 是构造，b=a 在 b 已存在时是赋值。隐式成员复制对裸指针通常只复制地址，拥有资源的类型需要正确管理复制语义，或使用 RAII 成员。

## 深入解释

```cpp
T a;
T b = a;  // 拷贝构造：b 尚未构造
b = a;    // 拷贝赋值：b 已经存在
```

常见签名为 `T(const T&)`；语言允许其他符合条件的 cv/reference 形式，不应把唯一签名背成标准定义。拷贝构造能否自动生成、是否被删除，还受成员、基类和用户声明的其他特殊成员函数影响。

编译器生成的拷贝通常逐成员处理：整数复制值，裸指针复制地址，vector 等成员调用自己的拷贝操作。裸指针并不自动深拷贝所指资源。
