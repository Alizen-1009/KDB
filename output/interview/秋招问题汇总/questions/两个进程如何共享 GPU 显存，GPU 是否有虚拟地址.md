# 两个进程如何共享 GPU 显存，GPU 是否有虚拟地址？

- 整理状态：已整理
- 题目出处：用户提供的《英伟达 AI Infra 五面面经》截图，AI Infra 硬件与算子第 7 题；2026-11-05 收录，实际面试日期与具体轮次未提供。

## 原题与条件

两个进程能同时操作同一个 GM 地址吗？GM 有虚拟地址吗？

## 30 秒回答

GPU 有虚拟地址机制，两个进程数值相同的指针不自动指向同一物理显存。需要通过 CUDA IPC 或可共享虚拟内存分配的导出/导入机制显式共享，映射后的虚拟地址可以不同。共享同一物理数据后仍要同步，UVA 也不意味着跨进程指针天然通用。

## 深入解释

需要区分三个问题：地址数值是否相同、是否映射同一物理分配、是否允许并发读写。

典型流程：

1. A 创建适合跨进程共享的设备分配。
2. A 导出句柄，将句柄通过进程间通道传给 B。
3. B 导入并映射，得到自己地址空间可用的指针。
4. 通过事件或其他受支持同步方式协调生命周期与访问。

CUDA IPC 和虚拟内存管理的共享接口各有平台、设备、分配方式和 API 约束，不能说任意 malloc 指针都能直接传递。共享读通常容易组织；存在并发写时要明确原子作用域、同步与数据竞争规则。

UVA、Unified Memory 和跨进程共享是不同概念；同一指针数值不能作为共享成功的证据。
