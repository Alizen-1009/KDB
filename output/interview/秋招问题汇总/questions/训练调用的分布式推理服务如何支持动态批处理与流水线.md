# 训练调用的分布式推理服务如何支持动态批处理与流水线？

- 整理状态：已整理
- 题目出处：[小红书分享图转录](https://chatgpt.com/library?file_id=libfile_08e498b5bde48191b68600b6e5b9507d&account_id=personal)，第 18 题

## 原题与条件

18. 假设你需要为 LLM 训练设计一个分布式推理服务，要求支持动态批处理和流水线并行，请描述整体架构，包括模型分片策略、通信拓扑和容错机制。

## 30 秒回答

原题同时写训练与推理。以训练流程调用独立 rollout 服务为前提，入口路由到有匹配权重版本的副本，组内按 TP×PP 切分，调度器按 token 和 KV 容量做 continuous batching。

## 深入解释

TP 优先留在快互连域，PP 相邻 stage 走 P2P，按计算和激活通信分段，用多个 microbatch 减少气泡。长 prefill 分块控制 TPOT。单 rank 故障隔离整组，按已输出 token 和 KV 恢复条件重建或重试。请求绑定版本与唯一 ID，处理旧版本 draining 和样本去重，测 TTFT、TPOT、吞吐与尾延迟。
