# 如何用 CUDA 直方图和前缀和查找第 K 大元素？

- 整理状态：已整理
- 题目出处：用户提供的“小鹏汽车三面｜端侧 AI Infra 面经”

## 30 秒回答

先固定输入类型、值域和 `K` 的定义：假设整数落在有限个桶里，`K` 从 1 开始且重复元素也计数。每个 block 在 shared memory 统计局部直方图，再归并成全局 `hist[v]`；对桶号从大到小求累计数，找到第一个 `count(≥v) ≥ K` 的桶。若桶与整数一一对应，`v` 就是答案；若一个桶覆盖多个值，要在命中桶中继续细分或做选择，不能直接把桶边界当答案。

## 深入解释

固定例子：`[7, 2, 7, 5, 1]`，第 `2` 大是 `7`，第 `3` 大是 `5`。从高值向低值累计：到 `7` 的计数是 `2`，到 `5` 的计数是 `3`。等价地，可先算升序前缀和，再定位第 `N-K+1` 小；注意相等值和 1-based `K`。

```text
输入：x[0..N-1]，1 <= K <= N，整数值域 [lo, hi]
1. 令 B = hi - lo + 1，清零全局直方图 H[0..B-1]
2. 每个 block 清零 shared 直方图 h，再让线程按 grid-stride 读入元素：
   对每个 v，atomicAdd(h[v-lo], 1)
3. block 内同步；将 h 归并到 H（全局原子或写部分直方图后单独归约）
4. 对 H 从大到小做 scan，找首个累计值 >= K 的桶 b；返回 b + lo
```

- **共享内存优化**：把每个元素对全局桶的 atomic 更新改为 block 内局部更新，最后每个 block 每桶至多归并一次；若热点值极集中，shared atomic 仍会冲突，可做 warp 私有桶、分片直方图或聚合。桶过多时，shared memory 占用会限制并发。
- **循环批量处理**：每线程一次处理若干连续/交错元素以摊销调度与归并成本，但要让相邻线程访问连续地址，检查寄存器占用。数据能否命中 L2 取决于工作集与复用距离；单纯增加循环批量并不保证提高 L2 命中率或减少一次完整扫描所需的输入读取字节数。
- **大值域**：若 `B` 太大，按高位 radix 建少量桶，确定包含第 `K` 大的桶并更新桶内 rank，再按低位细分；例如 32-bit 整数按每轮 8 bit 分四轮。每轮仍需扫描候选数据，不能把粗桶边界直接返回。浮点数需要定义 NaN、±0、无穷大及可排序编码。
- **验证**：与 CPU 排序基线比较空输入、非法 `K`、全相等、重复值、负数、值域边界和随机输入；性能按 `N`、桶数、分布偏斜程度测 kernel 总时间，并与 GPU sort/selection 比较。
