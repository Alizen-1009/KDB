# 不用临时变量交换两个 int 时加减法与异或法有什么边界？

## 原题与条件

不用额外空间，交换两个 int 变量的值：加减法和异或法分别怎么做？

## 30 秒回答

加减法可代数交换，但 C++ 有符号整数溢出是未定义行为，不能对任意 int 安全使用。异或法适用于整数，但两个引用若指向同一对象会把值清零，需要先排除别名。实际代码通常使用 std::swap，由编译器优化。

## 深入解释

加减法，仅在所有中间结果可表示时讨论：

```cpp
a = a + b;
b = a - b;
a = a - b;
```

不能认为“最后会减回来，所以中间 signed overflow 没关系”。无符号整数的模运算规则不同，但仍要考虑类型和同一对象别名，不混写成任意 int 的安全实现。

异或法，对可能引用同一对象的形参：

```cpp
void xorSwap(int& a, int& b) {
    if (&a == &b) return;
    a ^= b;
    b ^= a;
    a ^= b;
}
```

不要把多次修改压进一个复杂表达式。异或交换不承诺比普通交换快；“不用显式临时变量”和机器是否使用寄存器是不同层面。
