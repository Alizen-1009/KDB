# Global Router 与 Scheduler 如何分工？

- 整理状态：已整理
- 题目出处：用户本次提供

## 30 秒回答

Global Router 依据全局但可能滞后的实例健康、队列、容量和前缀位置做跨副本及 P/D 选择；本地 scheduler 根据实时 token budget、KV page 和公平性决定准入、每步组批、抢占及释放。前者不应假设远端状态强一致，后者是资源和缓存命中的最终裁决者；拒绝、重路由、租约、版本和反馈闭环处理竞争。具体边界是系统设计，不代表某框架默认实现。
