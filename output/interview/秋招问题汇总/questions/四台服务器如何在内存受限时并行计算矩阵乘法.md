# 四台服务器如何在内存受限时并行计算矩阵乘法？

- 整理状态：已整理
- 题目出处：用户提供的《英伟达 AI Infra 五面面经》截图，AI Infra 与推理系统第 12 题；2026-11-05 收录，实际面试日期与具体轮次未提供。

## 原题与条件

4 台服务器，每台 memory 大小是 N*N，服务器之间网络全连接，计算 C=A*B，A 和 B 都是 [N,N]，怎么并行？如果缓存空间只有 N*N/8，矩阵乘并行方案怎么做？

## 30 秒回答

将四机组成 2×2 网格，各负责一个 C 分块，用 SUMMA 式沿行广播 A panel、沿列广播 B panel，再本地累加 GEMM。缓存不够时继续按 M/N/K 分块、流式加载，约束同时驻留的输入、累加器和通信缓冲；先澄清容量单位，以及缓存是否等于全部内存。

## 深入解释

设 N 可被分块尺寸整除，容量先以“同精度矩阵元素数”计；若题目给 bytes，要按 dtype 转换，FP32 累加 BF16 输入也要单独计字节。

四机坐标为 (i,j)，i,j∈{0,1}，各持有 A_ij、B_ij、C_ij：

$$C_{ij}=A_{i0}B_{0j}+A_{i1}B_{1j}$$

采用 SUMMA 式 panel 广播：K 方向分段，各行广播所需 A panel，各列广播所需 B panel，各机更新本地 C。全连接网络允许这些通信，但不意味着广播没有成本或天然重叠。

### 每机容量为 N²

A/B/C 本地大分块各 N²/4，合计 3N²/4；还必须预留接收/打包缓冲。不能再随意同时接收两块 N²/4 的完整输入。若接收 panels 形状分别为 (N/2)×k 和 k×(N/2)，两份缓冲合计 Nk，保守要求 Nk≤N²/4；双缓冲则进一步缩小 k。真实预算还要包括元数据等。

### 工作空间只有 M=N²/8

若完整数据仍可从主存/其他 rank 读取，可只常驻 A/B/C 的小 tiles。三个同尺寸 t×t tiles 的简化预算：

$$3t^2\le M,\qquad t\le\frac N{\sqrt{24}}$$

这不是唯一最佳 tile；累计精度、通信双缓冲和输入常驻方式都会改预算。

```text
for 本机负责的每个 C tile:
    初始化输出累加器
    for 每段 K:
        读取或接收 A tile、B tile
        累加 C tile += A tile @ B tile
    写回 C tile
```

若 N²/8 指每机全部可用内存，四机总共只有 N²/2 个元素容量，连完整 A 和 B 都放不下，必须有外部存储、流式输入或其他明确数据来源。
