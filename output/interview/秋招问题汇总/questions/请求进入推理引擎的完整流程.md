# 请求进入推理引擎后经历哪些步骤？

- 整理状态：已整理
- 题目出处：用户本次提供

## 30 秒回答

请求经 HTTP 网关鉴权、限流和模型路由，tokenizer 编码并校验长度与采样参数；引擎入队，scheduler 按预算和 KV 可用性准入、查找前缀、分配缓存并组批。Prefill 计算 prompt 和首 token，decode 迭代执行、采样、追加 KV，逐步 detokenize/流式返回；遇终止条件、取消或超时后释放引用和资源。PD 分离时还有 P 到 D 的状态及 KV 交接；具体首 token 归属和组件边界因实现而异。
