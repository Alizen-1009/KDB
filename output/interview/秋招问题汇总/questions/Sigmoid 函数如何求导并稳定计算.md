# Sigmoid 函数如何求导并稳定计算？

## 原题与条件

Sigmoid 函数是什么？怎么求导？

## 30 秒回答

Sigmoid 为 σ(x)=1/(1+e^(−x))，导数为 σ(x)(1−σ(x))，在零点最大为 1/4，两端饱和时趋近零。数值实现可按 x 的正负分支，避免计算很大的正指数。

## 深入解释

$$\sigma(x)=\frac1{1+e^{-x}}$$
$$\sigma'(x)=\frac{e^{-x}}{(1+e^{-x})^2}=\sigma(x)(1-\sigma(x))$$

稳定计算：

```text
x >= 0: 1 / (1 + exp(-x))
x <  0: exp(x) / (1 + exp(x))
```

两种分支的指数输入都不大于零，避免极负 x 时直接计算 exp(−x) 溢出。结果靠近 0 或 1 时仍受有限精度影响，不代表无限精度实现。导数变小也解释了饱和区的梯度问题。
