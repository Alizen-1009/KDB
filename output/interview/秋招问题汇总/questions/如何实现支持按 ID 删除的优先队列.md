# 如何实现支持按 ID 删除的优先队列？

- 整理状态：已整理
- 题目出处：[小红书分享图转录](https://chatgpt.com/library?file_id=libfile_08e498b5bde48191b68600b6e5b9507d&account_id=personal)，第 23 题

## 原题与条件

23. 实现一个支持动态插入和删除的优先队列，要求每次操作时间复杂度为 O(log n)，并说明在 GPU 上实现的挑战。

## 30 秒回答

用数组二叉堆。插入后上浮，删除堆顶时末尾填洞再下沉。任意删除需要 ID 到 heap_index 的映射。

## 深入解释

每次 swap 更新映射；删任意位置后根据与父节点关系决定上浮或下沉。连续 ID 用预分配索引表可达严格 O(log n)，有序映射可只对被删 ID 查找并借助堆节点持有稳定映射条目直接更新位置，避免每次交换再查表。GPU 难点是堆顶争用、串行路径和离散访存；可按语义选批处理或近似分片。
