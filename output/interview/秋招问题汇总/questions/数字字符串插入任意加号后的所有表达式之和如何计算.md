# 数字字符串插入任意加号后的所有表达式之和如何计算？

- 整理状态：已整理
- 题目出处：用户提供的《英伟达 AI Infra 五面面经》截图，算法题第 7 题；2026-11-05 收录，实际面试日期与具体轮次未提供。

## 原题与条件

数字字符串，插入任意加号，求总和。

## 30 秒回答

先约定求的是所有插入方式对应表达式值之和。维护表达式数量 cnt、总值 total 和所有表达式最后一项之和 last。追加数字 d 时分插加号和拼接两类，得到 total′=2total+9last+2cnt·d、last′=10last+2cnt·d、cnt′=2cnt，无需枚举 2^(n−1) 种情况。

## 深入解释

题意按“在每个相邻数字间选择插或不插加号，求全部表达式值总和”解释；不是只求一个表达式、最小值或最大值。

例如 123 的四种方式为 123、1+23、12+3、1+2+3，总和 168。

维护 cnt、total、last。每个旧表达式值 x、最后一项 a，追加 d 后：

- 插加号：新值 x+d，最后一项 d。
- 不插：最后一项 a 变成 10a+d，新值 x+9a+d。

对全部旧表达式求和：

$$total'=2total+9last+2cnt\cdot d$$
$$last'=10last+2cnt\cdot d,\qquad cnt'=2cnt$$

首位初始化 cnt=1、total=last=首位数字。后续更新必须使用旧状态，不能先覆盖 cnt/last 再代入。

```python
def sum_all_expressions(s):
    # 前提：s 是非空十进制数字串，所有切分均允许。
    cnt = 1
    total = last = int(s[0])
    for ch in s[1:]:
        d = int(ch)
        total, last, cnt = (
            2 * total + 9 * last + 2 * cnt * d,
            10 * last + 2 * cnt * d,
            2 * cnt,
        )
    return total
```

O(n) 次状态转移、O(1) 个状态。Python 大整数的位数会增长，因此实际位复杂度和字节空间不是严格 O(n)/O(1)；固定模数时可逐步取模。若禁止多位数前导零，当前不加区分的合并状态不足以直接套用，需要另外处理合法切分。
