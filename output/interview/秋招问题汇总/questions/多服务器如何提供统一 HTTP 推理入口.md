# 多服务器推理服务如何提供统一 HTTP 入口？

- 整理状态：已整理
- 题目出处：用户本次提供

## 30 秒回答

在多副本前部署高可用负载均衡和无状态 API gateway，统一鉴权、限流、模型版本、请求 ID 与流式响应；服务发现和健康检查维护可用实例，router 根据负载和缓存状态选择后端。长连接需处理取消、超时、背压，已输出 token 后不能无条件透明重试；需要故障隔离、可观测性与滚动发布。HTTP 入口统一不意味着 KV 物理共享。
