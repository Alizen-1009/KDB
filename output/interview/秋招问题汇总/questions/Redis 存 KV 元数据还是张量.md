# Redis 应存 KV metadata 还是 tensor，数据实际在哪里？

- 整理状态：已整理
- 题目出处：用户本次提供

## 30 秒回答

一种设计是 Redis 存前缀哈希、模型版本、持有节点、块标识和租约等 metadata，实际 tensor 留在各 worker 的 GPU HBM，或按实现卸载到 CPU 内存、远端缓存等；读取数据仍需通过数据平面传输或重算。Redis 不天然知道 GPU 地址是否有效，也不保证记录与 GPU 生命周期原子一致，需版本、TTL、确认及失效回退。Redis 可以存字节串，但把大 tensor 放入它是另一种有序列化和网络成本的架构，并非必然选择；不声称某框架默认如此。
