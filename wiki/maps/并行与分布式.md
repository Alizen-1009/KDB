# 并行与分布式

## 导读

训练侧和推理侧要分开看。

训练侧按“切什么”排：[[../concepts/数据并行|数据并行]] → [[../concepts/DDP|DDP]] → [[../concepts/ZeRO|ZeRO]] → [[../concepts/FSDP|FSDP]]（切状态）；[[../concepts/Tensor Parallelism|Tensor Parallelism]]、[[../concepts/流水线并行|流水线并行]]、[[../concepts/Sequence Parallelism|Sequence Parallelism]]（切模型与序列）；[[../concepts/Expert Parallelism|Expert Parallelism]]（切专家，配合 [[../concepts/MoE|MoE]] 读）。

推理侧的 Context Parallel 分两阶段读：[[../concepts/Prefill Context Parallel|PCP]] 用 sequence 并行分摊超长 Prefill 计算，[[../concepts/Decode Context Parallel|DCP]] 分片 Decode 历史 KV；[[../concepts/DP Attention|DP Attention]]则按请求副本组织，别混着套。DeepSeek/MLA 的多请求扩展可继续读 [[../concepts/Wide Expert Parallelism|Wide Expert Parallelism]]：Attention 用 DP，Experts 用宽 EP；通信与尾部问题分别由 [[../concepts/Dual Batch Overlap|DBO]]、[[../concepts/Expert Parallel Load Balancing|EPLB]] 等处理。

底座：[[../concepts/集合通信|集合通信]]、[[../entities/NCCL|NCCL]]、[[../concepts/Torch Distributed|Torch Distributed]]。理解通用 collective 后，再读 [[../entities/NCCL Extensions|NCCL Extensions]]：`nccl_ep` 把 MoE dispatch/combine 做成专用通信路径，[[../concepts/跨 Mesh 权重重分片|跨 Mesh 权重重分片]]则解释在线 RL 中训练权重如何转换成 Rollout Mesh 的布局；两者都涉及 [[../concepts/通信-计算重叠|通信-计算重叠]]。
