# 投机解码

## 导读

先读总纲，再沿两类 drafter 路线展开：

1. [[../concepts/Speculative Decoding|Speculative Decoding]] —— 总纲：候选生成、target 验证、接受率与加速比。
2. **顺序 / 模型内 drafter**：[[../concepts/Multi-Token Prediction|Multi-Token Prediction]] → [[../concepts/MTP Drafter|MTP Drafter]]，理解如何把多 token 草稿能力训进模型或轻量辅助模块。
3. **并行 drafter**：[[../concepts/并行投机解码|并行投机解码]] → [[../concepts/DFlash|DFlash]] → [[../concepts/DSpark|DSpark]]，理解 diffusion-style 并行 proposal、target hidden context，以及按 confidence 与硬件曲线自适应选择验证长度。

GLM-5.2 与 GLM-5.3-Flash 还展示了一个独立的 Indexer 优化：`index_share_for_mtp_iteration=true` 让 MTP iterations 复用 DSA top-k indices。它不同于 [[../concepts/IndexShare|IndexShare]] 的跨 Transformer 层共享；Flash 只有前者，没有 5.2 式跨层共享。
