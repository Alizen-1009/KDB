# 注意力机制

## 导读

主干是从数学到 kernel 再到结构改造这条线：

1. [[../concepts/Online Softmax|Online Softmax]] —— 一切分块 attention 的数学前提，不理解递推就看不懂后面。
2. [[../concepts/FlashAttention|FlashAttention]] —— IO-aware tiling，把 N×N 矩阵从 HBM 里消掉。
3. [[../concepts/Flash Decoding|Flash Decoding]] —— decode 阶段 batch 小、KV 长，靠 split-KV 把并行度补回来。
4. [[../concepts/MLA|MLA]] → [[../concepts/FlashMLA|FlashMLA]] —— 前者是模型侧压 KV 的结构，后者是让它在 Hopper 上跑得动的 kernel。
5. [[../concepts/Online Softmax|Online Softmax]] → [[../concepts/Ring Attention|Ring Attention]] —— 把分块精确合并从单卡 kernel 扩展到跨 GPU KV block 流水；再与 [[../concepts/DeepSpeed Ulysses|Ulysses]] 的 Q/K/V All-to-All 布局转换对比。

[[../concepts/混合注意力|混合注意力]]、[[../concepts/Chunked Gated Delta Rule|Chunked Gated Delta Rule]]、[[../concepts/CSA-HCA|CSA-HCA]] 是另一条分支：不再优化标准 attention，而是换掉它。读 GDN/KDA 时先看 [[../concepts/线性注意力递归状态|线性注意力递归状态]]，区分短期 Conv State 与长期矩阵状态。
