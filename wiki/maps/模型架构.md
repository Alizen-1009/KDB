# 模型架构

## 导读

[[../concepts/MoE|MoE]] 是这个主题里最厚的一页，也是主干。其余按改造的部位分：

- **归一化与残差路径**：[[../concepts/RMSNorm|RMSNorm]] → [[../concepts/PreNorm Dilution|PreNorm Dilution]]（问题）→ [[../concepts/Attention Residuals|Attention Residuals]]、[[../concepts/Hyper-Connections|Hyper-Connections]]、[[../concepts/mHC|mHC]]（三种改法）
- **稀疏容量怎么分**：[[../concepts/Conditional Memory|Conditional Memory]] + [[../concepts/Sparsity Allocation|Sparsity Allocation]]（与 MoE 互补的另一条稀疏轴）
- **Gemma 系结构**：[[../concepts/Per-Layer Embeddings|Per-Layer Embeddings]]、[[../concepts/Double-Wide MLP|Double-Wide MLP]]
- **动态可学习状态**：[[../concepts/TTT Layer|TTT Layer]]，理解如何把 RNN 隐藏状态改造成测试时持续更新的 learner 权重，以及它与 linear attention、KV Cache 的边界。

理解稀疏容量时，在 [[../concepts/MoE|MoE]] 之后可读 [[../concepts/LatentMoE|LatentMoE]]：它区分模型 hidden size `d`、潜在维度 `ℓ` 与 expert intermediate size `m`，并把权重带宽、EP 通信和 Expert/Top-k 预算放到同一张账本里。

阅读 Qwen3.8-Flash-Next 时，建议按 [[../entities/Qwen3.8-Flash-Next|模型总览]] → [[../concepts/Gated Residual|Gated Residual]]（残差）→ [[../concepts/N-gram Embedding|N-gram Embedding]] → [[../concepts/Conditional Memory|Conditional Memory]]（加速器外容量）展开；token mixing 的 GDN/QSA 路径转到 [[注意力机制]]。DeepSeek-V3.2-Exp 则从 [[../entities/DeepSeek-V3.2-Exp|模型页]] 进入，在 [[../concepts/MLA|MLA]] 上仅增加 DSA，机制细节同样转到 [[注意力机制]]。

GLM 建议从 [[../entities/GLM-5 系列|GLM-5 系列]] 版本导航进入：5/5.1 是 DSA 主线，5.2/5.3 增加或继承 [[../concepts/IndexShare|IndexShare]]，[[../entities/GLM-5.3-Flash]] 则是完全不同的 KDA + DSA + mHC + Vision 新 Base；不要把 Flash 当作 5.3 的量化或蒸馏版本。
