# 重计算

## 定义

主动放弃保存部分中间激活，在需要时重新计算，以换取更低内存占用或更少内存访问的优化方法。

## 它解决什么问题

- 缓解训练或复杂算子中的激活存储压力
- 在某些 memory bound 场景下，用额外计算换取更好的整体性能

## 核心机制

- 不完整保存中间状态
- 在 backward 或后续阶段重新执行部分前向计算
- 用更多 FLOPs 换更少的全局内存读写
- PAI-FA 的 `head_dim=256` Backward 把原约 5 次 MMA 的单 kernel 拆成 `dQ` 与 `dKdV` 两个 kernel，合计约 7 次 MMA；重复重算 `S/P/dP/dS` 的目的不是减少 HBM 激活，而是避免 `dQ/dK/dV` 同时占满 [[Tensor Memory|TMEM]]，换取更大的 tile 和更高 Tensor Core 利用率

## 关键权衡

- 内存占用和内存访问下降
- 额外计算成本上升，是否值得取决于当前瓶颈是 memory 还是 compute
