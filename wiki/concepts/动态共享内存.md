# 动态共享内存

## 定义

`动态共享内存` 是 CUDA kernel launch 时通过第三个参数按 block 分配的 shared memory，对应 kernel 内的 `extern __shared__` 声明。

## 它解决什么问题

- 允许同一个 kernel 根据 launch 配置或问题规模，在运行时决定每个 block 需要多少 shared memory
- 适合 tile size、临时缓存大小或 reduce workspace 需要随配置变化的场景

## 核心机制

- Kernel launch 形式为 `kernel<<<grid, block, shared_mem_bytes, stream>>>(args...)`
- 第三个参数 `shared_mem_bytes` 单位是 byte，表示每个 block 额外申请的动态 shared memory
- 不传第三个参数时，等价于传 `0`
- `extern __shared__ T buf[]` 只声明动态 shared memory，不包含长度信息，CUDA 不会自动推断大小
- 若访问 `extern __shared__` 但 launch 时没有申请或申请不足，会形成越界访问，结果属于未定义行为
- 静态 shared memory `__shared__ T buf[N]` 由编译期决定大小，不依赖 launch 第三个参数
- 每个 block 的 shared memory 总量是静态 shared memory 加动态 shared memory

## 关键权衡

- 动态 shared memory 让 kernel 更灵活，但每个 block 使用越多 shared memory，每个 SM 可驻留 block 数可能越少，进而降低 [[Occupancy]]
- 如果 shared memory 用于显著减少 global memory 访问，即使 occupancy 降低，整体性能仍可能提升
- 动态 shared memory 的地址布局仍需要考虑 [[Bank Conflict]]
