# 混合注意力

## 定义

在不同层交替使用不同注意力/序列建模机制，以兼顾效率和全局依赖能力。已有页面最初覆盖 sliding/full attention；新的 SGLang KDA 来源补充了另一种形态：MLA full-attention 层与 KDA/GDN 递归线性注意力层交错。

## 它解决什么问题

- 避免所有层都使用 full attention 带来的高昂成本
- 同时保留周期性的全局信息交换能力

## 核心机制

- 大部分层采用 sliding attention 处理局部上下文
- 周期性插入 full attention 层捕捉全局依赖
- 通过层职责分工达到更好的长上下文计算平衡
- MLA/KDA 混合模型还要维护两类状态：MLA 层使用按 token 增长的 KV Cache；KDA/GDN 层使用按请求、按层固定大小的 Conv State 与矩阵状态
- Runtime 必须协调 Token KV Pool 与递归状态池，Prefix Cache 则只能在两类状态都可恢复的边界复用

## 关键权衡

- 局部层更高效，但全局建模能力有限
- 全局层补足长程依赖，但会带来更高计算开销
