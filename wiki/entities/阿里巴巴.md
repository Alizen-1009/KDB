# 阿里巴巴

## 一句话说明

阿里巴巴是中国互联网与云计算公司；在本知识库当前语境中，它主要作为 [[RTP-LLM]] 的开源方和生产部署场景提供方出现。

## 类型

- 组织 / 公司

## 核心信息

- 来源称 RTP-LLM 来自阿里巴巴大模型预测团队多年生产环境打磨，并已部署在淘宝、天猫、菜鸟等业务线。
- 本来源把阿里生产推理场景描述为高并发、动态负载、多模型、多模态和频繁模型更新的综合系统问题。
- 相关开源线索包括 GitHub `alibaba/rtp-llm` 和官方文档 `rtp-llm.ai`。
