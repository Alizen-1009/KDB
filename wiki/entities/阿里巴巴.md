# 阿里巴巴

## 一句话说明

阿里巴巴是中国互联网与云计算公司；在本知识库当前语境中，它既作为 [[RTP-LLM]] 的开源方和生产部署场景提供方出现，也通过 [[阿里云 PAI 团队]] 参与 GPU kernel 优化。

## 类型

- 组织 / 公司

## 核心信息

- 来源称 RTP-LLM 来自阿里巴巴大模型预测团队多年生产环境打磨，并已部署在淘宝、天猫、菜鸟等业务线。
- 本来源把阿里生产推理场景描述为高并发、动态负载、多模型、多模态和频繁模型更新的综合系统问题。
- 相关开源线索包括 GitHub `alibaba/rtp-llm` 和官方文档 `rtp-llm.ai`。
- PAI-FA 来源称阿里云 PAI 团队为 Qwen3.5 等 `head_dim=256` 训练场景实现了 FlashAttention-4 专用 Forward/Backward kernel，并通过 Dao-AILab/flash-attention PR #2412 合入社区仓库。
- 该 kernel 工作围绕 [[../concepts/Tensor Memory|TMEM]]、2-CTA/DSMEM、warp specialization 与异步 pipeline 展开；“千卡规模训练”和 benchmark 数字仍需绑定代码与训练配置。
- Qwen Team 的 2026-08-26 论文给出 [[Qwen3.8-Flash-Next]] 模型线：`125B` 主干总参数、每 token 激活 `6B`，另有加速器外 `51B` n-gram embedding 参数；架构结合 GDN/QSA hybrid、四分支 GR 与 Muon。
